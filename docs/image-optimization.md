# Optimasi aset gambar

43 aset PNG lokal dikonversi menjadi WebP lossless memakai Pillow/libwebp. Semua hasil diverifikasi dengan membandingkan dimensi serta seluruh byte piksel RGB/RGBA setelah decode; transparansi tetap identik. Tidak ada profil ICC pada sumber yang perlu dipindahkan.

Total PNG: 9027033 byte. Total WebP: 5257446 byte. Pengurangan: 41.8%.

Referensi komponen memakai WebP. Sumber PNG tetap tersedia untuk kompatibilitas URL lama dan favicon; SVG tetap vektor. Media remote dari database dan API upload tidak diubah. Optimizer Next.js tetap menawarkan AVIF/WebP sesuai dukungan browser.
